# 🛡️ CubeCheck

**CubeCheck** — это комплексный автоматизированный чекер для проведения проверок игроков на читы. Программа создана для того, чтобы максимально упростить и ускорить процесс как для модераторов, так и для проверяемых игроков.

Больше не нужно тратить время, искать и скачивать десятки сторонних утилит — всё необходимое уже собрано в одном месте и готово к работе сразу после установки.

---

## ✨ Основной функционал и встроенный софт

Программа включает в себя весь необходимый комплекс инструментов для глубокого анализа системы:

* 🔍 **Автопроверка** — автоматическое сканирование системы на наличие следов популярных читов и запрещенного софта.
* 🛠️ **Встроенный софт (без необходимости скачивания):**
* **Everything** — моментальный поиск скрытых файлов и остаточных логов по всей системе.
* **Process Hacker / Process Explorer** — продвинутый мониторинг активных процессов, скрытых дескрипторов и потоков.
* **ShellBag MRU Viewer** — просмотр истории открытия папок, даже если они были удалены.
* **Autoruns** — детальный анализ автозагрузки, служб и скрытых записей в реестре.


* 🖥️ **Системный аудит:**
* Вывод точной даты и времени установки Windows.
* Отображение времени последнего очищения корзины (помогает выявить быструю очистку следов перед проверкой).
* И другие критически важные для проверки системные метрики.

## 📥 Как скачать и запустить

### Для игроков и модераторов:

1. Нажмите на файл `CubeCheck_Setup.exe` в списке файлов выше.
2. Нажмите кнопку **Download** в правой части экрана для загрузки установщика.
3. Запустите скачанный файл и установите программу.

> 💡 **Для разработчиков:** Полные исходные коды проекта доступны в архиве `CubeCheck-sources.zip`.
